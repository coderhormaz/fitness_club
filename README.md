# Fitness Club

A static fitness club website built with plain HTML and CSS — no framework, no build step. The site files live in the `fitnessclub-final/` folder.

## Live Demo

https://fitnessclub-final.netlify.app/

## Features

- Fitness quiz
- Daily challenge
- Goal setting
- Blog
- Chatbot
- Diet planner
- Class / activity schedule
- Downloadable weight gain and weight loss PDFs

## Tech Stack

- HTML
- CSS
- Static hosting (Netlify)

## Getting Started

No install or build is needed. Either:

- Open `fitnessclub-final/index.html` directly in a browser, or
- Serve the `fitnessclub-final/` folder with any static host or local static server.
